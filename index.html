Serve this folder over HTTP

This app uses ES modules, which browsers refuse to load from a file:// URL. Run a static server inside the project folder and open the printed address: 

python -m http.server 8000

then open http://localhost:8000.

Any static server works (VS Code Live Server, npx serve, XAMPP, IIS…).
